删除任务

不勾选时只删除网关侧的任务记录，节点上的文件保持原样 —— 这是默认行为，也是最安全的。 勾选后网关会向节点下发删除；当前调度内核尚未落地，因此若节点侧没有文件记录，网关会明确报错而不是假装成功。
